## ✅ Funcionalidades

- 👥 Gerenciamento completo de atletas (cadastro, gols, cartões, mensalidades)
- 💰 Módulo financeiro (receitas vs despesas)
- 📊 Planilha de devedores e pagantes com cobrança via WhatsApp
- 🏆 Cards animados de artilharia (Mês, Semestre, Ano)
- 📤 Exportação CSV e Backup/Restauração JSON
- 👔 Multi-Administrador (múltiplos grupos isolados)
- 🛡️ Perfil do gestor com logo e chave Pix
- 📱 100% responsivo (Android e iOS)
- 🔒 Período de teste de 5 dias + chave de ativação
